# MetaACO на задаче «Резервирование товара»

Поиск использовал замороженные результаты 1836 маршрутов той же учебной задачи.
Для монолитных маршрутов взята первая серия, для компонентных — исправленная.
Из них 1685 исторически прошли приёмку. Для оценки качества использованы 1716
подтверждённых исходов успеха или провала тестов. Остальные исходы сохранены,
но исключены из оценки вероятности успешного решения.

Десять поисков с seeds 0–9 выполнили по 100 локальных оценок настоящим
многоколониальным MetaACO. Восемь выбрали route-0001, один route-0011,
один route-0069. Прогноз длительности каждого навыка и модели — медиана
измеренного времени узла, округлённая вверх до секунд. Это прогноз из опыта.
В данной проверке ранжирование учитывает оценку качества и прогноз времени.
Стоимость непосредственно в целевой функции не оптимизируется, действует
ограничение допуска. Выбор дешёвого маршрута является наблюдаемым результатом.

## Реальная повторная проверка

Каждый из трёх выбранных маршрутов исполнен три раза последовательно через
DeepSeek Flash с исходным кодом задачи и закреплёнными Docker-тестами.

| Маршрут | Состав | Прошли тесты | Медиана времени успешных, с | Медиана стоимости успешных, USD |
|---|---|---|---:|---:|
| route-0001 | Реализация → рефакторинг | 3/3 | 5.041 | 0.000522 |
| route-0011 | Реализация + тестовый план → интеграция → рефакторинг | 3/3 | 6.462 | 0.001033 |
| route-0069 | Реализация → ревью → рефакторинг | 2/3 | 7.108 | 0.000871 |

Одна попытка route-0069 провалила GREEN, следующие этапы остановлены.
Всего 25 API-вызовов, расчётная стоимость всех девяти попыток $0.006556.
Учёт полный во всех девяти попытках. Подробности — results.jsonl и replay.json.

## Границы вывода

Это проверка восстановления хороших маршрутов по полной истории той же задачи.
Качество на новой задаче, преимущество над random/fixed/bandit и экономия при
сборе неполной истории требуют отдельных экспериментов. Обычный runSkillAttempt
по-прежнему исключает историю самой задачи из прогноза качества; этот опыт
подан экспериментальному Python-запуску явно. Производственный режим переноса
опыта этим запуском не изменён.

Каждый исторический маршрут имел одну попытку. Три повтора лидеров дают
предварительное представление о стабильности. Повторные запуски выполнялись
последовательно, исходные серии — четырьмя работниками. Сравнивать абсолютное
время этих серий без учёта нагрузки нельзя. Общие прогнозы исходного перебора
не использованы как измерения.
