# Вехи завершения dsh-metaaco

При возобновлении работы сверить этот документ, открытые PR и фактические тесты.

1. **В работе — поиск графа и моделей внутри MetaACO.** Муравьи выбирают навыки,
   зависимости и назначения моделей из правил. Сравнить на малом примере
   с полным перебором и исполнить выбранный план через Harness с независимыми
   проверками. Сохранить колонии, UCB, феромоны, репликацию, элитный архив и
   локальный поиск. Соблюдать ограничения бюджета и обязательных проверок.
2. **Открыто — проверка пользы обучения.** Заморозить учебную историю и сравнить
   режимы на независимых задачах с несколькими повторами. Сохранить все семь
   baseline из архитектуры, качество, время, стоимость и провалы. Реальные
   DeepSeek-вызовы проводить только в согласованном бюджете.
3. **Открыто — воспроизводимый релиз.** Завершить ревью PR, проверить чистую
   установку на Lenovo, задокументировать параметры и показать в отчёте
   граф, модели, трассу поиска, сгенерированные файлы и независимые тесты.

База до совместного поиска — main@5ef0d6e (PR #20–23). Публичный
`dsh-metaaco/orchestration/skills` принимает каталог навыков, модели,
прогнозы, ресурсы и бюджет. Встроенный MetaACO декодирует перестановку
в состав графа, назначения моделей и приоритеты готовых узлов.
Harness исполняет выбранные приоритеты, TDD Evaluator проверяет код,
а Strategy Bank сохраняет решение и исход.

На контрольном графе из четырёх узлов совместная оценка улучшила прогноз
с 15 до 11 секунд, совпав с полным перебором расписаний. Это не гарантия
оптимума на других графах. Сквозные офлайн-тесты проверяют исполнение.
В текущем оптимизаторе бюджет — жёсткое ограничение, а минимизируется
прогнозная длительность. Расширение целевой функции,
полная научная серия и чистая установка остаются открытыми.

Трасса поиска структуры сохраняется в артефакте template-selection.
Панель показывает до 100 оценок с приоритетами, назначениями, прогнозом
длительности и отклонениями по бюджету. Повторные посещения учитываются
как оценки солвера. Индивидуальные идентификаторы колоний в этой трассе
пока отсутствуют.

17 ноября 2026, Lenovo, model-routing-v1. Оба режима прошли независимые
тесты на event-range. Flash-only использовал Flash на обоих шагах
(5,829 с, 375 microunits). Смешанный граф назначил Pro на реализацию,
Flash на REFACTOR (5,737 с, 977 microunits). Это одна пара, а прогнозы
4/2 с для реализации были гипотезой. Тарифы закреплены в адаптере по
[DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/).
Общий расчётный расход 1352 microunits, резервов этой серии нет.

Граф поиска поддерживает выбор между одним implement и группой implement-*
(не менее двух, с integrate). Компоненты получают общий контекст и передают
результаты в интеграцию. Узлы возвращают только изменённые файлы либо edits.
Совпадение пути у двух компонентов блокирует интеграцию. Офлайн-проверки
Harness покрывают успешную сборку и конфликт. Реальный Spring/S3 ещё не
запускался. Полная серия переноса и финальная проверка релиза остаются открытыми.

17 ноября 2026, Lenovo, transfer-series-v1, код cb82f28. На обеих новых
отложенных задачах прошли обязательные тесты с пустым и учебным снимками.
При отмене резерва учебный прямой шаблон занял 5,812 с и 286 microunits,
холодный по контракту — 9,499 с и 1422 microunits. На импорте CSV
соответственно 6,337 с и 1015 microunits против 13,154 с и 3298 microunits.
Порядок режимов менялся между задачами. С предыдущим event-range получены
три пары, по одной паре на задачу. Семирежимная серия с повторами остаётся
открытой. Новые расходы двух отложенных задач — 6021 microunits; вместе
с модельным пилотом — 7373 microunits без новых удержаний.

Для cb82f28 GitHub Actions прошёл. На Lenovo из нового checkout установлены
закреплённые зависимости, собран пакет и проверены импорт runSkillAttempt,
хеши встроенного решателя и локальный бенчмарк из распакованного пакета.
Проверка интерактивного запуска через профиль Harness и публикация пакета
отдельно не проводились.
