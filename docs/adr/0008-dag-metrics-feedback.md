# ADR 0008: scoped DAG observation и неизменяемый Feedback

Дата: 2026-11-14. Статус: реализовано в feature-ветке поверх `7b24512`.

Несколько Harness runs используют собственные seq, а live история меняется
между выборами. Глобальный наблюдатель и незакреплённая обучающая выборка приводят
к смешиванию расходов и невоспроизводимым решениям.

Решение: отдельная обёртка наблюдения регистрирует run IDs одного DAG, связывает
child sessions и сохраняет фактические settlement events через MetricsCollector.
Она не объявляет полное покрытие и не завершает сессию измерений до evaluator.
Ошибка учёта прерывает исполнение и явно возвращается вызывающему коду.
Существующие fixed workflow и публичные исполнители сохраняют поведение.

Feedback хранит manifest, policy и selector snapshot как неизменяемые Bank
artifacts с parent ref. Обновление явно вызывается только для train-истории;
выбор читает закреплённую версию. Используется существующий LinUCB, без замены
MetaACO, миграций БД или нового алгоритма награды. Общая валидация snapshot
экспортируется из Selector и применяется при чтении Feedback.

Следствия: требуется управление активным ref приложением; конкурентные версии
могут разветвляться. Frozen эксперимент воспроизводим относительно закреплённых
артефактов и candidates. Полнота API accounting, admission до каждого физического
запроса, управление экспериментами и автоматическая настройка policy не решены
этим ADR. Подробные контракты: [метрики и Feedback](../dag-metrics-feedback.md).
