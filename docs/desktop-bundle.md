# Установка в DeepSeek Desktop

Пакет объявляет `dsh.bundle.patch` и содержит `cordis.patch.yml`. Каталог
распакованного пакета можно добавить как локальный bundle. Исходный каталог
также подходит, если он содержит весь пакет, включая Python-решатель.
Манифест проверяется штатным механизмом Harness.

Без дополнительной настройки bundle добавляет `/metaaco` с демонстрационным
предпросмотром. Чтобы подключить поиск по навыкам, подготовьте задание командой
`node examples/prepare-skill-job.js --out NEW_DIR --docker-image sha256:IMAGE_ID`
и задайте абсолютный `skillJobFile` в конфигурации записи `metaaco`. Тогда
`/metaaco-skills` покажет задачу, модели и бюджет. Флаг `--allow-llm`
исполняет конкретное задание. Команда читает ключ из окружения процесса
Harness. Пароль, ключ и содержимое задания не входят в bundle.

После установки откройте новый сеанс, чтобы он получил обновлённый профиль.
Исполняющий профиль должен предоставлять workflowEngine и subagents.
В Harness 0.2.2 исполнение может находиться в контексте вызывающего агента.
Предпросмотр использует только реестр команд.

На Lenovo проверено добавление bundle в отдельный web-профиль 0.2.2-rc.3
и автоматическое включение patch в собранную конфигурацию. На модулях
0.2.2-rc.3 прошли 13 unit/contract и интеграционных проверок, в том числе
старые workflow и команда навыков с Docker и подставным API.
Текущий Desktop-профиль пользователя в эту проверку не входил.
