# Шаблоны стратегий v1

`compileStrategies` использует Task Analyzer и возвращает вход v1 для
`python/metaaco_variants.py`. Правила применимости используют тип задачи.
Изменение функциональности получает прямой вариант и вариант с контрактами.
Исправление ошибки и рефакторинг получают прямой вариант. Неизвестный или
неподдерживаемый тип требует уточнения классификации.

Навык задаёт задание и ожидаемый артефакт. Шаблон задаёт зависимости.
Компилятор добавляет описание, стек и требования задачи и привязывает выход
каждого предшественника ко входу следующего узла. Модель, ресурсные лимиты и
оценки задаёт вызывающая сторона. Версии закреплены в ID шаблонов.

Написанные агентом тесты — часть результата разработки. Независимая проверка использует закреплённые тесты из запроса. Компиляция
формирует вход для цикла исполнения.

Для сквозного запуска используйте экспорт `dsh-metaaco/orchestration/templates`.
`runTemplateAttempt` принимает параметры обычной попытки, `templateOptions`
и отображение `templateCandidates` из ID шаблонов в зарегистрированные стратегии.
Компилятор добавляет REFACTOR после итогового снимка реализации. Существующий
Evaluator проверяет RED до запуска агентов и GREEN до передачи снимка в REFACTOR.
Банк сохраняет выбор шаблона, результаты тестов и метрики успешных и неудачных попыток.
MetaACO оценивает расписания допустимых графов. Затем существующий contextual
bandit сравнивает зарегистрированные стратегии по закреплённому снимку Feedback
и политике пользователя. Каждому шаблону нужна отдельная стратегия или маршрут.
В отчёте fastestId обозначает вариант с лучшим прогнозом времени, а selectedId —
вариант, выбранный селектором. Банк сохраняет решение селектора с ID снимка.

Режим `compose: true` строит варианты из правил подключения навыков.
Проектирование добавляет контракт перед реализацией. Ветка тестов добавляет
подготовку тестов и интеграцию, которая ждёт оба результата. `modelChoices`
задаёт допустимые модели по навыкам, а `estimates[skill].byModel` позволяет
развести их прогнозы. Идентификатор связан со структурой и назначениями.
Ограничение — до 16 вариантов. Каждый из них остаётся входом существующего
MetaACO. Выбор структуры пока использует перебор допустимых комбинаций.
