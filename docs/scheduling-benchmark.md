# Проверка выбора порядка MetaACO

Команда `python3 -B python/scheduling_benchmark.py` запускает встроенный MetaACO
с тремя seeds и сравнивает его с фиксированным порядком и полным перебором
допустимых порядков на графе из четырёх задач.

При двух слотах обзор и документация (по 4 секунды) конкурируют за ресурсы
с правкой (1 секунда). Тесты (10 секунд) зависят от правки. Начать с обзора и
документации означает закончить через 15 секунд по прогнозу. Если начать правку
сразу, тесты могут стартовать на первой секунде, и оптимум составляет 11 секунд.

Время задач здесь задано вручную. Сравнение измеряет расчётное расписание;
solverWallTimeMs отдельно сообщает измеренное время работы решателя.
Полный перебор применим только к этому маленькому графу.

## Калибровка пилотом Lenovo

В пилоте `pilot.RdCbXiL8` сохранено по 21 успешному наблюдению GREEN и
REFACTOR. Медианы длительности узлов составили 1933,27 и 1934,18 мс.
Они включают проверку артефакта. Для расчётного сравнения правке присвоена
медиана GREEN, тестам — медиана REFACTOR. Независимым обзору и документации
присвоена медиана GREEN как приближение. После округления до целых секунд:

```sh
python3 -B python/scheduling_benchmark.py --durations 2 2 2 2
```

Фиксированный порядок даёт 6 секунд, MetaACO и полный перебор — 4 секунды.
Это прогноз для нового графа. В исходном пилоте был только последовательный
GREEN → REFACTOR, поэтому фактических замеров параллельного графа пока нет.

## Измерение исполнения через Harness (offline)

`node examples/scheduling-replay.js --out /new/output/directory` выполняет
тот же разветвлённый граф через опубликованный Harness и `runDag`.
Вместо сети используется локальный LlmAdapter с задержками 4/4/1/10 секунд.
Это синтетический replay, а не воспроизведение записанных ответов Lenovo.
API-ключи не читаются, тарификация и платные запросы отсутствуют.

Для seeds 7/11/42 выполняются парные fixed/MetaACO прогоны, порядок режимов
чередуется. MetaACO запускается заново для каждой пары с закреплённым встроенным
solver; JS независимо проверяет его план. Граф, модели и задержки неизменны.
Независимая проверка сверяет каждый выходной артефакт; зависимая задача дополнительно
проверяет полученный артефакт `patch`. Это проверка передачи данных, не TDD решения
задачи программирования: итоговое качество в Bank остаётся `inconclusive`.

Результаты сохраняются в `manifest.json`, `runs.jsonl`, `report.json` и `bank/`.
Новый запуск не перезаписывает существующий manifest. Журнал и Bank сохраняют
ошибки, при ошибке серия прекращается. Для MetaACO сохраняются полный план,
прогнозы, seed, параметры и хеши solver. Поля `measured` отдельно содержат
время планирования (включая Python subprocess), исполнения DAG и суммарное время
(включая создание и освобождение runtime). Timeline содержит наблюдаемые старты
и завершения адаптеров. `maxActive` показывает наблюдаемую конкурентность.

Интеграционный тест выполняет две пары с уменьшенными задержками, проверяет
конкурентность, зависимости, артефакты и приоритет критического пути. Он намеренно
не требует выигрыша по wall time: нагрузка ОС и запуск Harness могут изменить
результат короткого опыта. Для оценки ускорения на реальных LLM потребуется
отдельная серия с независимыми задачами и тем же контролем бюджета.

### Локальный замер 2026-11-15

Код replay: `a30e671`, Node v24.22.1, Mac; три пары seeds 7/11/42.
Медиана измеренного времени DAG: fixed **15,277 с**, MetaACO **11,170 с**.
Медиана полного времени с подготовкой/освобождением runtime и планированием:
fixed **15,286 с**, MetaACO **11,266 с**. Это около 26% в данном синтетическом
опыте; маленькая специально подобранная задача не доказывает общего преимущества.
Серия выполнялась параллельно с частью регрессионных проверок, поэтому нагрузка
среды не контролировалась. Все 24 артефакта проверены, конкурентность — два.
SSH к Lenovo завершился таймаутом установки соединения: серверный замер пропущен.
Платных API-вызовов не было.

## Небольшая серия с реальным API

`examples/live-scheduling.js --execute --out /fresh/directory --budget-microunits 800000`
(запускать через Node) использует существующий DeepSeek adapter и единый
BudgetController для всех шести исполнений. Требуются отдельное разрешение,
ключ в окружении и выделение суммы из общего пользовательского бюджета.
Скрипт сам не знает о расходах других серий: оператор обязан заранее вычесть
их и зарезервировать лимит этого запуска. Новый каталог обязателен.

Граф: review/docs/patch → tests (только tests зависит от patch), два слота,
seeds 7/11/42, чередование Fixed/MetaACO, максимум 24 запроса без retries.
Прогнозы по две секунды закреплены по предыдущему пилоту; review/docs — proxy.
Ответы — JSON-артефакты по задаче сложения: обзор, документация, выражение и
примеры тестов. Проверяется структура, но сгенерированный код не исполняется.
Это исследование latency настоящего API, не независимая оценка программирования:
качество остаётся inconclusive, Feedback не обновляется.

Завершённые и неудачные вызовы записываются в Metrics/Bank. При неизвестном
расходе резерв удерживается; после ошибочного исполнения серия останавливается.
Полные результаты и бюджет сохраняются в report.json; промежуточные — runs.jsonl.
Рассчитанная стоимость по peak-тарифу не равна подтверждённому счёту провайдера.
Тариф перепроверен по официальной странице 2026-11-15; секреты не входят в отчёты.

### Реальные запросы Lenovo, 2026-11-15

Код `7e1e201`, Node v24.22.3, встроенный solver, deepseek-flash, 24 запроса,
6 completed DAG. Все JSON-артефакты прошли описанные проверки структуры.
Полное время включает планирование и создание/освобождение Harness runtime:

| Seed | Fixed полное, с | MetaACO полное, с |
|---|---:|---:|
| 7 | 4,767 | 3,433 |
| 11 | 4,273 | 4,332 |
| 42 | 4,117 | 3,303 |
| Медиана | 4,273 | 3,433 |

Разница медиан — около 19,7%; одна из трёх пар медленнее с MetaACO.
Три пары на одной простой задаче не подтверждают статистического превосходства.
Планирование стоило 79–83 мс. Прогнозы не обновлялись по результатам этой серии.
Кеш провайдера и временная нагрузка могут влиять на результат.

Общий лимит серии — 800000 microunits USD. Расчёт по закреплённому peak-тарифу:
3056 microunits ($0,003056), 24 reconciled reservations, held=0, violated=false.
Это верхняя тарифная оценка по usage, не счёт провайдера; фактический off-peak
тариф может быть ниже. С учётом ранее учтённых 4650 microunits остаток общего
разрешения $9,50 составляет 9492294 microunits ($9,492294).
На сервере отдельно сохранены allocation и settlement, manifest, Bank,
планы с хешами solver, журнал и полный отчёт. Повторный запуск автоматически
не производится. Серверные offline-тесты нового launcher: 2/2; локальные
регрессии: 125 основных, 16 интеграционных, 17 Python, без пропусков.

Следующий эксперимент качества должен запускать независимые закреплённые тесты
на сгенерированном коде в Docker, включать разные задачи и больше пар. Текущие
completed нельзя использовать как успешные обучающие исходы Strategy Selector.
