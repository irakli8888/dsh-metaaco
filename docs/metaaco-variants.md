# Выбор между графами и моделями

`python3 -B python/metaaco_variants.py --problem variants.json --seed 42`
принимает JSON v1 с полями `schemaVersion`, `variants`, `requiredTasks` и
`budgetMicrounits`. Каждый из 1–16 вариантов содержит `id`, `problem`
(существующий DAG problem v2 с закреплёнными моделями) и `costMicrounits`
(внешний прогноз суммарной стоимости в USD).

Селектор отбрасывает варианты сверх бюджета и варианты без обязательных узлов.
Для каждого оставшегося варианта настоящий MetaACO строит расписание.
Селектор сравнивает прогноз длительности, затем стоимость и ID.
Результат содержит выбранный ID, существующий результат планирования и
таблицу оценок и причин отклонения. Проверка наличия узла не доказывает
прохождение тестов: это обязанность независимого evaluator.
Этот этап перебирает заданные варианты, а муравьи оптимизируют расписание
внутри каждого из них. Оценки не являются измерениями или гарантией оптимума.
