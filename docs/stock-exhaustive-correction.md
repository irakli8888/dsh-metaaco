# Исправленная серия резервирования товара

Исходная серия выполнила 1836 маршрутов по одной попытке. Приёмку прошёл 581
маршрут. Из 1255 неуспешных попыток 1198 остановились из-за конфликта файлов
компонентов. Общее задание противоречило распределению файлов между компонентами.

Исправленная серия сохраняется отдельно с теми же идентификаторами маршрутов.
stock.cjs реализует debit, subject.cjs использует этот интерфейс и реализует
reserve. Обязательные тесты и исходный код сохраняются. Компонентных маршрутов 1296.

Полнота расходов теперь подтверждается и для неуспешной попытки, если все
защищённые вызовы завершены и их токены сопоставлены с закрытыми резервациями.
У незавершённых вызовов полная стоимость остаётся неизвестной.

Предпросмотр без API — `node examples/run-stock-exhaustive.js --preview`.
Аргументы исполнения — `--execute OUT IMAGE WORKERS LIMIT SUBSET`, где OUT —
отдельный абсолютный каталог, IMAGE — закреплённый SHA-256 Docker-образ,
WORKERS — 1–4, LIMIT — 1–1836, SUBSET — all либо components.
Ключ передаётся через DEEPSEEK_API_KEY. Отчёт и results.jsonl обновляются после
каждой попытки. Манифест закрепляет задачу, тесты, исходные файлы и маршруты.

Возобновление допустимо после остановки предыдущего процесса с тем же манифестом.
Внешняя блокировка flock должна обеспечивать единственного владельца серии.
Прерванные попытки сохраняются. Один запуск на маршрут и параллельная нагрузка
ограничивают выводы о надёжности и времени. Повторы лидеров и проверка переноса
опыта на независимые задачи выполняются отдельными экспериментами.
