# Просмотр сохранённых запусков

Первая версия — автономный интерактивный HTML-снимок, не live-сервис.
Он создаётся на Lenovo из явно перечисленных банков и открывается на Mac:

```sh
node examples/inspect-runs.js --bank /path/to/results/bank \
  --bank /path/to/legacy/results --out /new/private/inspection.html
```

SQLite открывается readOnly, без StrategyBank constructor и миграций, каждый банк
читается в отдельной транзакции. Исходные файлы и эксперименты не изменяются.
Нет запуска агентов, API, сетевых запросов или выполнения сгенерированного кода.
Артефакты привязаны к попытке, проверяются размер и SHA-256; повреждения/отсутствие
показываются как ошибки. Лимит одного артефакта 2 MiB, превышение явно отмечается.

Разделы: граф и выбранный порядок, задания/ответы/файлы, длительности узлов и
записи API-расходов, независимая оценка и отчёты, исходные события и артефакты.
Граф из sidecar manifest показывается как входной; при его отсутствии явно
показывается только сохранённый dag-plan. Порядок — приоритеты готовых работ,
не линейное расписание. Полосы времени — длительности, не Gantt.

Важные ограничения: нет полной истории кандидатов отдельных муравьёв, нет
побайтового HTTP-промпта старых запусков. Задание узла не выдаётся за полный
запрос провайдеру. Отсутствующие evidence и неизвестное качество не превращаются
в успех. Банки прошлых запусков не дополняются выдуманными данными.

HTML содержит выбранные промпты, ответы и исходные данные. Экспорт только
в приватное место (0600), без перезаписи; файл не коммитить и не публиковать.
Это не средство автоматического удаления секретов из произвольных банков.
Не экспортировать банк с чувствительными данными без проверки. Штатные API-ключи
живут вне банков и экспортёр к ним не обращается. Данные вставляются как JSON
с экранированием HTML-разделителей и отображаются через textContent; CSP запрещает
сетевые обращения и формы. Для обновления нужно создать новый снимок.

Следующие отдельные этапы: наблюдение во время исполнения, полные provenance
промптов и тестовых логов, трасса кандидатов MetaACO. Панель не утверждает,
что эти этапы реализованы.
