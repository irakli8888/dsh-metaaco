# Пробный запуск DeepSeek через Harness

Из корня проекта команда `node examples/run-deepseek-tdd.js` показывает лимит
без сетевого запроса. Для реального запуска передайте `--execute`,
`--budget-microunits 610000` `--docker-image sha256:…` (локальный ID образа Node 24) и
`--out /путь/к/новому/каталогу`.
Ключ берётся из DEEPSEEK_API_KEY. Каталог создаётся эксклюзивно с правами 0700.

Фиксированная задача — исправить сложение. Сначала независимый Node evaluator
проверяет baseline и RED. Harness отправляет один текстовый запрос для GREEN и
только после прохождения тестов отправляет второй для REFACTOR. Валидатор запускает JavaScript в одноразовом контейнере без сети. Контейнер
получает только временный набор тестовых файлов и исходников в режиме чтения.
Ключ остаётся у процесса Harness.

Адаптер использует deepseek-flash, без tools, thinking и автоматических повторов.
На каждый вызов резервируется 301229 микродолларов по опубликованному пиковому
тарифу на весь контекст в 1M токенов и максимум 1024 выходных токена. Перед
разрешением реального вызова сверяйте [тариф](https://api-docs.deepseek.com/quick_start/pricing/).
Расчёт по usage не подтверждает списание. Если usage отсутствует или поток
завершился ошибкой, бюджет может оставаться зарезервированным.

Локальная интеграция запускает Harness и evaluator с подставным HTTP-ответом.
Первый прямой сетевой smoke и сквозной TDD-запуск проверяют разные границы.
