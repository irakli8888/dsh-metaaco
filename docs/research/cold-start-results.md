# Итоги cold-start пилота на резервировании товара

Серия stock-cold-start-online-v1 завершилась 20 ноября 2026, exit-status=0,
журнал содержит completed/count=700. Выполнено 700 уникальных попыток в 35 историях.
Все записи удовлетворяют historyCount=round. У каждой истории 20 попыток,
стартовая история пуста. Обязательные тесты прошли 674 попытки, 26 неуспешны.
Расчётная стоимость всех попыток $1.169737, неизвестной полной стоимости нет.
Контрольные семь запусков в эти числа не входят.

| Метод | Успехи из 100 | Расчётная стоимость USD |
|---|---:|---:|
| Random | 92 | 0.679479 |
| Fixed | 96 | 0.049796 |
| Cheapest | 99 | 0.050722 |
| Historical best | 98 | 0.051103 |
| Contextual bandit | 100 | 0.050399 |
| MetaACO without bank | 97 | 0.107320 |
| MetaACO with bank | 92 | 0.180918 |

В каждой из пяти историй cheapest, historical-best, contextual-bandit и обоих
MetaACO первый успех достигнут с первой попытки. Для fixed одна история потребовала
две попытки, остальные одну. Для random одна история потребовала четыре попытки,
остальные одну. Порядок seed в summary может отличаться от канонического, поскольку
первые результаты поступали в перемешанном порядке.

Fixed, cheapest, historical-best и contextual-bandit исполняли по одному уникальному
маршруту на историю. MetaACO with bank исполнил по 20 разных маршрутов в каждой
истории. Без банка посещались 6–10 маршрутов на историю. Random — 19–20.
На этой простой задаче пилот не показал преимущества MetaACO по успешности
или общей стоимости. Разницу 96/99/98/100 успехов среди использовавших один
маршрут методов нельзя приписывать улучшению выбора без дополнительных проверок
случайности ответов, кеша и порядка исполнения.

MetaACO with bank использовал постоянное least-observed исследование. Его результаты
характеризуют цену такой политики, а не эксплуатацию зрелого банка. Большинство
методов получило успех сразу, поэтому эксперимент имеет слабую чувствительность
к улучшению времени до первого успеха. Следующие отдельные исследования — frozen
эксплуатация, новые независимые задачи и оценка окупаемости обучения. Наличие
полной истории всех маршрутов не является условием полезного выбора.
