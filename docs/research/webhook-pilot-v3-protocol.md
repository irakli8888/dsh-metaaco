## Условия

Порядок и seed 7 фиксированы:

1. Direct Flash: один implement.
2. Direct Pro: один implement.
3. Fixed: Flash implement → refactor.
4. Components: Flash design → три независимые реализации → integrate → refactor.
   Модель выбирает файлы, обязанности и приватные интерфейсы; host проверяет
   пересечение владения. Реализации могут работать параллельно, максимум два слота.
5. MetaACO: тот же каталог Flash/Pro, пустая история, 100 локальных оценок,
   включая одну начальную. Никакого ручного выбора или замены победителя.

Preflight при $2 построил все пять планов. Предварительный MetaACO снова выбрал
Flash implement → refactor. Это известно до исходов, не является обучением или
оценкой качества. История каждой попытки изолирована; ни предыдущие пилоты,
ни результаты предыдущих условий этой серии не поступают в policy.

Перед каждой попыткой план строится с оставшимся бюджетом; фактические назначения
и trace сохраняются в manifest и могут отличаться от preflight при изменении
доступных ресурсов. Такой остаточный бюджет не позволяет строгого сравнения
эффективности методов. Нельзя менять протокол, промпты или код по промежуточным
результатам. Ошибки, blocked стадии и все расходы сохраняются; повторов нет.

Приоритет — independent acceptance correctness, TDD compliance отдельно.
Direct может пройти 12 target + 2 regression и иметь state=inconclusive из-за
отсутствия REFACTOR. Это не full TDD success. У остальных маршрутов последующие
стадии блокируются при провале обязательного GREEN. Неполное доказательство
не считается успехом.

## Ресурсы и доказательства

Общий предел 2000000 USD microunits. Следующая попытка получает бюджет за вычетом
spent + held прежних. Частичный/неизвестный usage удерживает резерв; отсутствие
учётного доказательства прекращает серию. Прогнозы отдельны от измерений и от
hard reservation. 8192 output tokens/call, 32768/attempt, input 262144 bytes,
artifact 65536 bytes, concurrency 2, API timeout 120s, attempt timeout 300s.

Node v24.22.1, Python 3.14.4. Подтверждены package.json установленных Cordis 4.0.5,
dsh-workflow-ptc 0.2.1-rc.2, dsh-agent 0.2.1-rc.2. Образ:

без сети, read-only, непривилегированный пользователь, memory/pids/CPU limits.
