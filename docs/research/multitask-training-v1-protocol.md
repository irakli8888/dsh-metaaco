# Первая новая учебная серия multitask-training-v1

Дата подготовки: 23 ноября 2026, Europe/Samara. До paid dispatch оператор разрешил
**до $5 суммарно**, максимум 24 исполнения: 3 новые задачи × seeds 7/11 × 4 раунда.
Это настоящий online-train с обновлением истории, не повтор frozen webhook-пилотов.
Исходы прежних validation-кандидатов/stock/held-out серий не импортируются.

## Задачи и данные

Новые независимые in-memory CommonJS задачи из examples/learning-tasks/:

| Train taskId | Публичная задача | Target/regression |
|---|---|---|
| lease-queue-train-v1 | FIFO очередь, исключительные аренды, сроки и stale tokens, повтор/лимит | 8 + 2 |
| wallet-ledger-train-v1 | Целочисленные переводы, идемпотентность, атомарный отказ, overflow | 8 + 2 |
| ttl-cache-train-v1 | TTL/LRU, дедупликация загрузок, ошибки, инвалидирование stale work | 8 + 2 |

Каждая имеет app.cjs с assertion RED и readonly README. Критерии полностью доступны
всем ролям; независимые tests/reference не передаются модели. Калибровка подтверждает
baseline и ожидаемые ERR_ASSERTION, затем GREEN/REFACTOR эталона. Контрольные мутации
постоянного lease token, перевода без проверки funds и stale cache commit обнаружены.
Это подтверждает стенд, а не полноту спецификации или качество LLM.

Серия **только train**: validation/test здесь пусты. Отложенная frozen проверка
переноса должна иметь собственные заранее объявленные независимые задачи и протокол.
Нельзя объявлять эту серию проверкой обобщения или позднее выдавать train за test.
Текущие задачи не заменяют семь baseline; сравнительный эксперимент — следующий этап.

## План обучения до просмотра реальных исходов

Внутри каждого раунда шесть ячеек task/seed детерминированно перемешиваются seed 7.
Только одна попытка серии активна, внутри DAG до двух агентов. Исходный source каждый
раз чистый; код предыдущей попытки модели не передаётся.

| Раунд (0-based) | Структурное ограничение | Seed 7 | Seed 11 |
|---|---|---|---|
| 0 | monolith | Свободные модели (минимальный prior выбирает Flash) | implement обязан Pro |
| 1 | components + обязательный design | design обязан Pro | integrate обязан Pro |
| 2 | Семейство и модели свободны | Только собственный прошлый опыт текущей задачи | То же, отдельная история |
| 3 | Семейство и модели свободны | То же | То же |

Первые 12 попыток — заранее стратифицированное исследование семейства/ресурсов,
а не свободный оптимальный выбор. Муравьи по-прежнему строят допустимый маршрут
из каталога: роли, модели остальных стадий и порядок; готовый source/DAG им не
подставляется. Внутренние файлы и интерфейсы компонент выбирает модель на design.
В первых двух раундах exploreTraining=least-observed-among-visited; в следующих
exploreTraining выключен. Это новый протокол, не изменение старой cold-start серии
с постоянным least-observed после просмотра её исходов.

Seeds имеют разные начальные resource strata: это две независимые истории, но
не две обменные одинаковые конфигурации для оценки причинного эффекта модели.
Четыре исхода на task/seed — небольшой диагностический training pilot, мощность
не обоснована. Классификатор и веса API-моделей не обучаются.

## История и настоящая интеграция MetaACO

Один SQLite Bank нужен для общего транзакционного series budget. Истории seed
разделены train task aliases <logicalTaskId>-seed-<seed> и разными immutable feedback
lineages; исходы другого seed в snapshot не попадают. Перед поиском дополнительно
фильтруется точный taskId: переноса качества между задачами в этой версии нет.
Снимок cutoff содержит только завершённые прошлые попытки; для round r должно
быть ровно r прежних исходов этой задачи, включая сохранённые неуспехи.

Success=1 только при succeeded, independently verified evaluation success и полном
учёте расходов. Failed с complete accounting получает 0 как end-to-end неуспех
стратегии (включая нарушение DTO); это не означает, что во всех случаях доказана
логическая ошибка исходника. Неопределённые/незавершённые исходы не подменяются нулём.
Все состояния сохраняются; инфраструктурные ошибки останавливают серию.

На каждой совместимой маршрутной идентичности (skill/model/dependencies, без
приоритета независимых узлов) обновляются attempts/successes. Качество оценивает
прежняя Beta(1,1) формула (successes+1)/(attempts+2); отсутствие опыта даёт prior 0.5,
а не провал. Для целочисленного objective posterior округляется вниз до 0.001. В Python objective остаются историческое качество и прогноз makespan,
не новое многокритериальное обучение измеренных времени/цены.

В раундах эксплуатации один лучший положительно наблюдённый маршрут возвращается
как warm-start choices (posterior, затем меньший pinned cost prior, затем route key).
Его, как и минимальный начальный кандидат, **оценивает та же колония**, расходуя
общий лимит 100 objective evaluations. Budget/trace и elite reinforcement фиксируются.
Затем работают обычные UCB колоний, репликация, мутации и local search. Это не
Historical Best вместо MetaACO и не внешний fake fallback. Совместимость choices
проверяется по текущему каталогу/ограничениям. При отсутствии положительных наблюдений
памятного seed нет, поиск остаётся настоящим. Измерения времени/токенов/стоимости
сохраняются, но priors этой серии не перекалибровываются по промежуточным данным.

## Ресурсы, остановки и воспроизводимость

Typed responseContract v2/job v3, readonly host restore. Flash/Pro с прежними
закреплёнными тарифами; API aliases не аттестуют неизменность cloud weights.
Solver seed детерминирован, API sampling этим seed не управляется.
На вызов 8192 output tokens/120s, на попытку 32768 output tokens,
262144 input bytes, 65536 artifact bytes, 2 слота. Deadline исполнения 300s;
локальный поиск имеет отдельный timeout 30s и сохраняемый overhead.
Docker image sha256:116b800c3754b440ee0aa3ed2f20f5bf3d99a554bfd9adeea09ea8017f6e85f5,
без сети, read-only, непривилегированный пользователь и лимиты ресурсов.

Глобальный бюджет 5000000 USD microunits. Перед каждым API-call резервируются
attempt и series ledger в том же Bank; settlement включает полные usage или held
при неопределённости. Series limit общий для всех задач/seeds. Для сохранения полной
доступности пула серия останавливается перед следующей попыткой, если остаток меньше
двух Pro-reservations: 2704882 microunits. Это консервативный stop, не цель потратить
весь разрешённый бюджет. Также stop: held/violation, incomplete accounting,
feedback failure, baseline/RED infrastructure failure, API 401/402/403/429, отмена.
Автоматического paid retry или resume нет; остановка может дать менее 24 исходов.

manifest/config hash, code/archive/version provenance закрепляются до вызовов.
На каждую попытку start-журнал fsync, decision JSON до dispatch (cutoff ref,
observed IDs, stats, intervention, choices, полный trace), Bank артефакты и фазы,
result fsync, summary и финальные immutable feedback refs. Эти refs — сохранённая
учебная история, не результат frozen evaluation. Полный Bank экспортируется также
при исключении. Не коммитить raw чувствительные данные; агрегаты и доказательства
добавить в научное досье независимо от успехов.
